# Naka TV

Appli Android TV / Fire TV pour https://naka.cx/app-tv

- Flèches : se déplacer entre les éléments (cadre jaune)
- OK : cliquer · OK maintenu (ou Menu) : mode pointeur souris
- Retour : ferme le plein écran / la fenêtre ouverte / page précédente (2x pour quitter)
- En plein écran vidéo : OK = pause/lecture, ← → = -10 s / +10 s
- Touches ⏯ ⏪ ⏩ de la télécommande gérées

L'APK est compilé automatiquement par GitHub Actions à chaque push :
https://github.com/Dreguel/naka-tv/releases/latest/download/NakaTV.apk
